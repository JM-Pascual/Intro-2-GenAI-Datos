# Introducción a los LLMs y el Generative AI

Material para la clase introductoria de IA Generativa de la materia **Ciencia de Datos** (Facultad de Ingeniería).

## Contenido

- **slides.html** — Presentación de la clase.
- **chat_base.py** — Script base para interactuar con un modelo de lenguaje usando Ollama.
- **requirements.txt** — Dependencias del proyecto (`ollama`).

## Requisitos

```bash
pip install -r requirements.txt
```

> Se requiere tener [Ollama](https://ollama.com) instalado y corriendo localmente.
